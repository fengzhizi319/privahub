# 产品需求文档 (PRD)

## 1. 产品定位

Privahub 是隐私计算平台 SecretPad 的 Go 语言后端实现，为前端 Web 控制台提供完整的 RESTful API 服务。它是 Java Spring Boot 版本的性能优化重构，保持 100% API 兼容性。

## 2. 目标用户

| 角色 | 使用场景 |
|------|----------|
| 平台管理员 | 节点管理、用户管理、系统配置 |
| 数据科学家 | 创建项目、构建 DAG 图、运行隐私计算任务 |
| 数据提供方 | 注册数据源、授权数据表、查看任务状态 |
| 运维人员 | 部署、监控、故障排查 |

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| API 响应时间 | P99 < 200ms | 非计算类接口 |
| 并发连接数 | 1000+ | 单实例 |
| 内存占用 | < 256MB | 空闲状态 |
| 启动时间 | < 3s | 冷启动到就绪 |
| 数据库查询 | P95 < 50ms | 单表查询 |

### 4.2 可用性要求

| 指标 | 目标值 |
|------|--------|
| 服务可用性 | 99.9% |
| 优雅关闭 | 支持（drain 30s） |
| 健康检查 | /health 端点 |
| 日志持久化 | 结构化 JSON 日志 |

### 4.3 安全要求

| 需求 | 实现方式 |
|------|----------|
| 认证 | JWT Token，可配置过期时间 |
| 密码存储 | bcrypt 哈希 |
| 传输安全 | 支持 TLS/HTTPS |
| 请求限流 | Token Bucket 算法 |
| IP 白名单 | CIDR 匹配 |
| 审计日志 | 写操作全量记录 |
| 路径遍历防护 | filepath.Abs + 前缀验证 |
| 请求体限制 | 可配置最大 Body 大小 |

### 4.4 兼容性要求

| 维度 | 要求 |
|------|------|
| API 兼容 | 与 Java 版本 100% 路由兼容 |
| 数据库兼容 | 支持 SQLite / MySQL |
| 前端兼容 | 无需修改前端代码 |
| Kuscia 兼容 | 支持 Kuscia 0.11+ |
| 配置兼容 | 支持环境变量覆盖 |

## 5. 技术约束

| 约束 | 说明 |
|------|------|
| 语言版本 | Go 1.21+ |
| Web 框架 | Gin（不引入其他框架） |
| ORM | GORM（支持 SQLite + MySQL） |
| 配置管理 | Viper（YAML + 环境变量） |
| 日志 | Zap（结构化日志） |
| 依赖注入 | 手动 Wire（不引入 fx/dig） |
| 部署方式 | 单二进制 + 配置文件 |
| CGO | 必须启用（SQLite 依赖） |

## 7. 与 Java 版本对比

| 维度 | Java (Spring Boot) | Go (Gin + GORM) |
|------|-------------------|-----------------|
| 启动时间 | ~15s | < 3s |
| 内存占用 | ~512MB | < 128MB |
| 部署产物 | JAR + JRE (~200MB) | 单二进制 (~30MB) |
| 并发模型 | 线程池 | Goroutine |
| 容器镜像 | ~800MB | ~50MB |
| 依赖管理 | Maven (多模块) | Go Modules |
| 配置方式 | application.yaml | privahub.yaml + env |
| 数据库迁移 | Flyway | GORM AutoMigrate |

## 8. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| CGO 交叉编译复杂 | 部署受限 | 提供 Docker 镜像 + 预编译包 |
| SQLite 并发写入 | 高并发下锁等待 | WAL 模式 + busy_timeout |
| Kuscia API 变更 | 接口不兼容 | 版本化客户端 + 适配层 |
| 前端隐式依赖 | 字段缺失导致 UI 异常 | 100% API 兼容性测试 |
